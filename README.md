# Веб-страна на МГА Новаци

Статична веб-страна (еден `index.html`) за Младинска Граѓанска Акција – Новаци и Младинскиот центар Новаци.

## Структура
- `index.html` – целата страна
- `slike/` – логото (`logo.png`) и фотографии
- `dokumenti/` – PDF-ови: статут, решение, годишни извештаи, програма

## Што да пополните пред објава
Пребарајте `ВНЕСИ` и `ИЗМЕНИ` во `index.html` – секое жолто обележано место е податок што треба да го внесете
(точно регистрирано име, ЕМБС, ЕДБ, адреса, е-пошта, претседател, работно време).
Кога ќе ги пополните, можете да ја избришете класата `todo` за да исчезне жолтата боја.

## Законски обврски (Закон за здруженија и фондации)
- Годишниот извештај за работа и финансискиот извештај за претходната година се објавуваат до **30 април** (чл. 23 и 53).
- Ако здружението добие статус од јавен интерес, и извештаите по чл. 85–86 се објавуваат на веб-страната до 30 април (чл. 87).

## Објава на GitHub Pages
1. Repository → **Add file → Upload files** → повлечете ги сите датотеки и папки → **Commit changes**.
2. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → **Save**.
3. По 1–2 минути страната е на `https://КОРИСНИЧКО-ИМЕ.github.io/ИМЕ-НА-РЕПО/`.
